# Ship fully scaffolded first, and throw sprinkles instead of dropping them

The teacher (Danna, Hampstead School) asked for a highly scaffolded Level 1, with later levels taking help away. We build only the fully scaffolded flow first. Each scaffold listed in `GLOSSARY.md` is still a separate piece that a URL flag can switch off later, so removing help doesn't mean rewriting the steps.

The teacher's spec also has sprinkles "fall smoothly from the top of the screen." We deliberately throw them instead, in arcs from the lower half of the screen edges, because it's livelier and closer to the Math Antics feel she asked for. A calmer drop from the top can come back later as an option. Don't "fix" the throwing to match her spec without asking her first.
